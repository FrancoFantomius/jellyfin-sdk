# Security Policy

## Supported Versions

The following table outlines which versions of `@francofantomius/jellyfin` currently receive security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4.x | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not open a public GitHub issue.

Instead, please report vulnerabilities by emailing Franco Fantomius or opening a private GitHub Security Advisory. Please include:
- A description of the issue.
- Steps to reproduce or a minimal proof of concept.
- The affected version(s).

All vulnerabilities will be acknowledged promptly and addressed in the next release.
